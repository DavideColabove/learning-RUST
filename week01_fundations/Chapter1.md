# Chapter 1: Getting started

We can build a project "cargo build" or "cargo check", we can build and run a project using "cargo run". \
Instead of saving the result of the build in the same directory as our code, core saves it in '/target/debug'; \
When you are ready for release you can compile it with optimizations using "cargo build --release" (in /target/release).

In Rust packages of code (such as dependencies) are called 'crates'.
